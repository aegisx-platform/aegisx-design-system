WCAG 2.1 contrast
verified at runtime.

Every --ax-text-* × --ax-background-* pairing is checked against the WCAG 2.1 formula using resolved CSS custom properties. Flip theme in the panel (or press T) to re-run. Thresholds: AA ≥ 4.5, AAA ≥ 7, non-text ≥ 3.

06How this works

Each cell's color and background are resolved through getComputedStyle. Relative luminance follows the WCAG 2.1 formula; contrast ratio is (L1 + 0.05) / (L2 + 0.05). Thresholds: AA normal text ≥ 4.5, AAA ≥ 7, non-text ≥ 3.
